RGB Color Classifier

  • Python
  • pandas
  • scikit-learn (KNN)
84.8%test accuracy, weighted F1 0.85

Supervised classification model that predicts a color label directly from RGB pixel values.

  • Loaded and explored a labeled RGB dataset (about 5,000 samples across 11 color classes) and checked the class distribution before modeling.
  • Split the data 80/20 with stratified sampling to preserve class balance in the train and test sets.
  • Trained a K-Nearest Neighbors classifier (k=5), reaching 84.8% accuracy on the test set (weighted F1 = 0.85).
  • Wrapped the model in a reusable predict_color() function and validated it against unseen sample pixels.
